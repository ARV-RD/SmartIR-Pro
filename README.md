# SmartIR Pro Remote Bridge - интеграция HomeAssistance

Интеграция-мост для **Home Assistant**, которая превращает ИК-пульты на базе **ESPHome** в нативные сущности домена `remote` с прямой поддержкой кодов **BroadLink Base64**.

Позволяет использовать готовую базу кондиционеров, телевизоров и вентиляторов из интеграции **SmartIR** (включая UI-форк `litinoveweedle/SmartIR`) без конвертации JSON-файлов и без правки YAML-конфигураций.

---

## Как это работает

1. **SmartIR** отправляет стандартную команду `remote.send_command` со строкой вида `b64:JgBQAAAB...` на виртуальный пульт `remote.smartir_pro_*`.
2. **SmartIR Pro Remote Bridge** отбрасывает префикс `b64:` и передает чистую Base64-строку в API-сервис вашего ESPHome-устройства (`esphome.<имя_устройства>_send_b64`).
3. **Контроллер с прошивкой ESPHome** на лету декодирует пакет BroadLink и излучает ИК-сигнал.

---

## Требования (Прошивка контроллера)

Для работы интеграции требуется устройство в ESPHome, предоставляющее API-сервис `send_b64` (принимает строковый параметр `code` в формате BroadLink Base64).

* Готовая конфигурация прошивки для модулей на базе чипа **BK7231N**: [SmartIR-Pro-BK7231N](https://github.com/ARV-RD/SmartIR-Pro-BK7231N)

---

## Установка интеграции через HACS

1. Откройте в Home Assistant **HACS → Меню (три точки в правом верхнем углу) → Пользовательские репозитории**.
2. Вставьте ссылку на репозиторий: `https:__github.com_ARV-RD_SmartIR-Pro`
3. В поле **Категория** выберите **Интеграция (Integration)** и нажмите **Добавить**.
4. Найдите в списке **SmartIR Pro Remote Bridge**, нажмите **Скачать** и **перезагрузите Home Assistant**.

---

## Настройка и привязка к SmartIR

1. Перейдите в **Настройки → Устройства и службы → Добавить интеграцию**.
2. Найдите и выберите **SmartIR Pro Remote**.
3. Задайте понятное название пульта (например, `Пульт Зал`) и выберите из выпадающего списка сервис вашего контроллера (`*_send_b64`).
4. В системе появится сущность **`remote.pult_zal`**, которую можно сразу указывать в качестве контроллера при добавлении устройств через графический интерфейс **SmartIR**.
